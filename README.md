# react
A single-page React app built with Vite that connects to a REST API (built in WA-2) to create, view, edit, and delete tasks.

Features

Four routes with React Router: task list, task detail, create task, edit task, plus a 404 page
All data fetched from the live API, with no hardcoded mock data
Visible loading spinners, error messages with retry, and empty states
Client-side form validation before any request is sent
State handled with useState, a custom useFetch hook, and useContext
Responsive layout for mobile and desktop
